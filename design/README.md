# Filosoff — natural profile design

Personal GitHub profile for Filosoff. The GitHub account login remains decoder-dev.

## Direction

Warm charcoal, off-white, muted sage and coral. A soft illustrated avatar and a matte fabric wave replace the original glossy chrome treatment. Plain, personal English copy replaces the advertising-style headings. A complete Russian edition is available through the language switch near the top of each README. One flagship project, a short selection of other work, and a compact toolbox. Core descriptions remain real text so they reflow on phones and work with screen readers. No remote stats widgets or image-service dependencies.

- Charcoal / panel: `#171c1c`
- Off-white: `#e8e5df`
- Sage: `#bfd2a7`
- Coral: `#cc8c80`
- Muted text: `#b4bdaa`

## Assets

- `assets/hero-profile.png`: final banner edited with the built-in imagegen tool, 2172 × 724 pixels.
- `assets/avatar.png`: final illustrated avatar edited with the built-in imagegen tool, 1254 × 1254 pixels.
- `assets/avatar.jpg`: the same avatar re-encoded as JPEG for upload; the illustration is unchanged.
- `assets/private-music-en.svg`: editable project panel with a vector signal motif.
- `assets/private-music-mobile-en.svg`: a separate compact composition with larger text for phones.
- `assets/private-music-ru.svg` and `assets/private-music-mobile-ru.svg`: localized Russian panels for `README.ru.md`.
- `assets/private-music-desktop.png` and `assets/private-music-player.png`: unmodified interface previews from PrivateMusicDesktop, shown in an expandable gallery and labeled as demo data.
- `assets/signal.svg`: optional divider, archived rather than repeated in the final README.

The profile keeps its native GitHub theme. The banner and project panel are intentionally dark on either theme; surrounding text follows GitHub's light or dark appearance. No profile display preference is changed. The current prompts are in [prompts.md](prompts.md).

## Profile references

Reviewed the public profiles and profile README sources of [Anthony Fu](https://github.com/antfu), [Cassidy Williams](https://github.com/cassidoo), [Sindre Sorhus](https://github.com/sindresorhus) and [Anurag Hazra](https://github.com/anuraghazra).

Applied principles: compact useful navigation, a short personal introduction, a clear current project and a carefully selected native GitHub pinned section. The illustrations, copy and project panel are specific to this profile; no reference assets or biography claims were copied. A calm, self-contained layout was chosen instead of adding external stats widgets. No skills, employment, contact details or achievements were invented.

## Portfolio polish

The README highlights actual listening features, platform integration and the implementation stack. Screenshots stay in an expandable gallery to keep the introduction compact. Six pinned repositories use concise English descriptions and relevant topics. The profile status points to Private Music. GitHub program badges and earned achievements stay in the native sidebar; no badge artwork or fake statistics are added to the README.
